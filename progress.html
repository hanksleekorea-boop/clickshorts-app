R2 확인 기준: 현재 앱 P0 입력 약속은 화면·브라우저 자동 확인 21/21과 빠른 전체 재검사 13/13을 통과했습니다. 실제 USB 기기 재확인은 별도 증거로 남아 있습니다.

R3 진행 방식: 중요하고 안전한 일을 먼저 만들고, 확인 결과와 파일 목록이 맞는지 끝에 다시 확인합니다.

R4 완료 전망: 현재 완료 전망은 10/25이며, P0 화면·자동 검사는 사용자 없이 계속하고 실제 기기·공급자 확인은 별도 증거로 분리합니다.

R5 현재 한계: 실제 링크 본문 읽기, 영상·음성 받아쓰기, 실제 기기 재확인과 실제 공급자 연결은 아직 없습니다.

R6 더 나은 방법: 더 나은 방법은 현재 앱의 정직한 입력 안내를 먼저 완성하고, 실제 처리 기능은 서버 준비 뒤에만 열어 오해를 막는 것입니다.

R7 더 좋은 요청 문장: 다음 P0 항목인 작업 상태·다시 시도·저장 범위 안내를 현재 앱에 이어서 구현해줘.

R7 멈춤 사유: 사용자 없이 할 수 있는 P0 화면·자동 검사 작업은 계속 가능하며, 실제 기기와 공급자 확인만 별도 대기입니다.

R8 코칭: 사용자 요청을 ‘실제 처리 기능’과 ‘화면에서 미리 알릴 기능’으로 나누면, 아직 없는 기능을 완성처럼 보이지 않게 관리할 수 있습니다.
